\section*{Major Projects}

\small 
\textbf{Wet-Dry Cycler for RNA Production} \\
Recruited and led a team to design and build an automated system to simulate early Earth conditions for non-enzymatic RNA synthesis, supporting origins-of-life research in collaboration with Dr. David Deamer. This project included:
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=0pt,parsep=0pt,partopsep=0pt]
  \item \textbf{Embedded control:} C/C++ on ESP32-S3 (ESP-IDF) with a finite-state machine, timers/ISRs, watchdog, safe-state recovery, and JSON telemetry/logging.
  \item \textbf{PCB \& electronics:} Custom PCB integrating DRV8825 stepper drivers, DC mixing motor control, heater switching, NTC thermistor sensing, limit switches, and a 12V/5V power tree with fusing and grounding; benchtop validation with DMM/scope.
  \item \textbf{Web server \& UI:} Node/Express service with a React dashboard using WebSockets for live status/commands, interlocks, scheduling, and log export.
  \item \textbf{Submodules:} Thermal plate; syringe-pump rehydration/manifold; vial motion stage; mixing motors; CO\textsubscript{2} purge/flow; extraction/refill; limit switches \& sensors; power distribution.
  \item \textbf{Delivery \& support:} Delivered to an Eden Rock lab; trained users and documented procedures; continuing maintenance and regular communication with the PhD researchers operating the system.
\end{itemize}


\textbf{3D Tracking Using an IMU for Rock Climbing} \\
Designed a 9-DOF BNO055–based motion tracker with a minimal MCU state machine for on-wall movement analysis.
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=0pt,parsep=0pt,partopsep=0pt]
  \item \textbf{Embedded:} Calibration→Recording→Waiting state-machine control; BNO055 orientation/linear-accel with timestamped accel/gyro/mag data is sent over serial.
  \item \textbf{Data/analysis:} PC logging (CoolTerm) and MATLAB filtering/visualization; validated with gym wall trials.
\end{itemize}

\textbf{Mechatronics Competition (2nd Place)} \\
Led development of an autonomous robot for timed ball collection/deposit with robust real-time control under randomized field constraints.
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=0pt,parsep=0pt,partopsep=0pt]
  \item \textbf{Embedded/RT control:} C on PIC32 with interrupt-driven state machine, watchdogs, and debounced sensors. 
  \item \textbf{Sensors/electronics:} 6 bumpers, 5 IR tape sensors; H-bridge motor control; regulated 5V (servo) and 3.3V (sensors/encoders); reverse-polarity protection with power LEDs, heatsinked 3.3V regulator; noise-reduced sensor wiring.
\end{itemize}
